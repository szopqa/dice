# Project
Small TypeScript/Node project used to test the agent factory.

## Commands
- Test: `npm test`
- Lint: `npm run lint`
- Build: `npm run build`

## Conventions
- Specs live in `specs/`, one file per feature, acceptance criteria numbered AC-1, AC-2…
- Every AC must be covered by at least one test that names it, e.g. `it("AC-2: rejects empty title")`.
- Never commit to main. Never merge PRs. Never force-push.
